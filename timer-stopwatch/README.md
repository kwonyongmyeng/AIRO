# 타이머 · 스톱워치

뽀모도로 집중 타이머 겸 스톱워치. 정적 HTML **1파일**이라 별도 설치·빌드 없이 브라우저로 바로 씁니다.

## 무엇을 하나요

- **뽀모도로 타이머** — 집중(25분)·짧은휴식(5분)·긴휴식(15분) 프리셋 + **직접 시간 설정(1~180분)**, 종료 시 **알림음**
- **스톱워치** — 시작·정지·계속, 초기화, **랩(구간) 기록**
- 알림은 **소리로만** 알려줍니다(브라우저 알림 권한 요청 없음)
- 데이터는 **저장하지 않습니다** — 기록 누적·다운로드 기능 없음, 새로고침하면 초기화

## 데이터 예시

- 타이머 입력: `집중 25분` 또는 직접 설정 `50분`
- 스톱워치 랩 출력: `랩 1 · +00:12.3 · 00:12.3` / `랩 2 · +00:13.5 · 00:25.8`

## 실행 방법

`index.html` 파일을 브라우저에서 열면 끝입니다.

```bash
# 로컬에서 바로 열기
open index.html          # macOS
# 또는 파일 더블클릭
```

> 알림음은 브라우저 정책상 **시작 버튼을 한 번 누른 뒤부터** 재생됩니다(사용자 조작 필요).

## 배포 (선택)

정적 파일이라 어디든 올리면 동작합니다.

```bash
# Vercel 예시
npm i -g vercel
vercel               # 이 폴더에서 실행
```

## 기술 메모

- **의존성 0개** — 외부 라이브러리·CDN·API 없음
- 알림음은 파일 없이 **Web Audio API** 비프음으로 생성
- 순수 HTML + CSS + JavaScript (`index.html` 단일 파일)
