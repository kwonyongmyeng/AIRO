# AIRO

## 🎙️ 라이브 5개국어 통역기 (`/live-translate/`)

말하는 즉시 한국어를 **영어 · 일본어 · 중국어(간체) · 스페인어 · 프랑스어** 다섯 가지 언어로 번역해 화면에 띄우는 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 열립니다.

- 페이지: `live-translate/index.html` (배포 주소 예: `https://<사용자이름>.github.io/AIRO/live-translate/`)
- 별도 서버·빌드 도구 없이 동작하는 단일 HTML 파일입니다.

### 주요 기능

| 기능 | 설명 |
| --- | --- |
| 실시간 음성 인식 | 브라우저 내장 Web Speech API로 말하는 내용을 받아 적습니다(크롬·엣지 권장). |
| 5개국어 동시 번역 | 문장이 끝날 때마다 다섯 언어 카드가 동시에 갱신됩니다. |
| 말하는 중 미리 번역 | 문장을 끝내기 전에도 중간 결과를 미리 번역해 보여 줍니다(설정에서 끌 수 있습니다). |
| 출력 언어 변경 | 독일어·베트남어·러시아어·인도네시아어·태국어를 추가하거나 뺄 수 있습니다. |
| 음성 재생 | 카드의 🔊 버튼으로 번역문을 읽어 주고, 한 언어는 자동 재생도 가능합니다. |
| 발표 모드 | 설정 영역을 감추고 전체 화면으로 전환해 강의·행사장 화면에 띄우기 좋습니다. |
| 기록 저장 | 번역 기록을 시간과 함께 텍스트 파일로 내려받을 수 있습니다. |
| 직접 입력 | 마이크를 쓸 수 없는 환경에서는 문장을 입력해 번역합니다. |
| 글자 크기 조절 | 화면 전체 글자 크기를 0.8~1.8배로 조절합니다. |

### 사용 방법

1. 크롬 또는 엣지에서 페이지를 엽니다(마이크는 `https` 주소에서만 동작합니다).
2. **🎤 통역 시작**을 누르고 마이크 권한을 허용합니다. 스페이스바로도 시작·정지할 수 있습니다.
3. 한국어로 말하면 아래 다섯 개 카드에 번역문이 차례로 나타납니다.

### 번역 엔진

- 기본값은 **무료 엔진**으로, API 키 없이 바로 사용할 수 있습니다. 한 곳이 막히면 다른 공개 엔드포인트로 자동 전환합니다.
- 사용량이 몰리면 응답이 느려지거나 실패할 수 있으므로, 중요한 행사에서는 설정에서 **Google Cloud Translation API 키**를 넣어 사용하시길 권합니다.
- 입력한 키는 브라우저의 로컬 저장소에만 남으며 외부로 전송되지 않습니다.
- [검증 필요: 2026-09 기준] 무료 공개 번역 엔드포인트의 정책과 한도는 제공 사업자 사정에 따라 바뀔 수 있습니다.
