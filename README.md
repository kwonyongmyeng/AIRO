# AIRO

Google AI Studio 앱 빌드 결과물과 상세페이지 정적 파일을 함께 담고 있습니다.

## 파일 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | AI Studio 앱 진입점 (`assets/` 번들 사용) |
| `hero.html` | AI 업무비서 강의 상세페이지 히어로 섹션 |
| `images/` | 이미지 리소스 |

## hero.html 사용법

**1. 강사 사진 넣기**

`images/instructor.jpg` 경로에 배경이 제거된 인물 사진(PNG 권장, 세로 비율)을 넣으면 자동으로 표시됩니다.
파일이 없으면 사진 자리에 점선 안내 박스가 대신 보입니다.

```
images/instructor.jpg
```

**2. 문구 수정**

`hero.html` 본문의 배지·헤드라인·서브카피·불릿 3개·CTA 텍스트를 직접 수정하면 됩니다.
CTA 링크는 `href="#apply"`로 되어 있으므로 실제 신청 페이지 주소로 바꿔 주세요.

**3. 크기 수정**

캔버스 내부 수치는 1920×1080 시안 기준 px을 그대로 쓰고 `--s`(스케일 단위)를 곱하는 방식입니다.

```css
font-size: calc(58 * var(--s));   /* 시안의 58px */
```

앞의 숫자만 바꾸면 모든 화면 폭에서 비율이 유지된 채 함께 조정됩니다.

## 레이아웃 동작

- **901px 이상**: 1920×1080 16:9 캔버스가 화면 폭에 맞춰 비율 그대로 축소됩니다.
- **900px 이하**: 세로 흐름으로 전환되어 텍스트가 위, 강사 사진이 아래로 배치되고
  본문 글자는 읽기 가능한 최소 크기(약 15px) 아래로 줄어들지 않습니다.
