# 오목 대전 (2인 플레이)

한 화면에서 두 사람이 번갈아 두는 오목 게임입니다. 별도 설치 없이 `omok/index.html`을 브라우저로 열면 바로 실행됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조(바둑판, 조작 버튼, 전적 패널) |
| `style.css` | 색상 토큰, 레이아웃, 반응형·다크모드 스타일 |
| `script.js` | 게임 로직, 승리 판정, 전적 저장, 캔버스 렌더링 |

## 기능

- **15줄 바둑판** — 캔버스로 그리며 화면 크기에 맞춰 자동으로 조절됩니다. 좌표(A~O, 1~15)와 화점을 표시합니다.
- **시작 / 다시하기 / 무르기 / 종료**
  - 시작: 새 판을 열고 흑돌(선공)부터 진행합니다.
  - 다시하기: 현재 판을 버리고 곧바로 새 판을 시작합니다(진행 중이면 확인창).
  - 무르기: 마지막 착수 한 수를 되돌립니다(진행 중일 때만).
  - 종료: 판을 접고 대기 상태로 돌아갑니다. **종료한 판은 전적에 반영되지 않습니다.**
- **승률 표시** — 흑·백 각각 `승 ÷ (승 + 패) × 100`으로 계산합니다. 무승부는 승률에서 제외하고 `n전 n승 n패 n무`로 따로 표시합니다.
- **전적 저장** — 플레이어 이름, 승·패·무, 최근 대국 10건을 브라우저 `localStorage`에 저장합니다. 저장소를 쓸 수 없는 환경(시크릿 모드 등)에서도 게임 자체는 정상 동작합니다.
- **장목 옵션** — 기본값은 자유 오목(6목 이상도 승리). 체크를 해제하면 정확히 5목일 때만 승리로 인정합니다.
- **보조 정보** — 착수 수, 경과 시간, 마지막 착수 좌표, 승리한 다섯 점 강조 표시.

## 조작 방법

1. 오른쪽 패널에서 두 사람의 이름을 입력합니다(선택).
2. `시작`을 누르면 흑돌 차례로 대국이 시작됩니다.
3. 교차점을 클릭(또는 터치)해 돌을 놓습니다. 교차점에서 반 칸 이상 벗어난 클릭은 오조작 방지를 위해 무시됩니다.
4. 5개를 먼저 이으면 결과 창이 열리고 전적이 자동으로 갱신됩니다. `한 판 더`를 누르면 이어서 다음 판을 진행합니다.

## 전적 초기화

`전적 초기화` 버튼으로 승·패·무와 최근 대국 기록을 모두 지웁니다. 지운 기록은 되돌릴 수 없습니다.
